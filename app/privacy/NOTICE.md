The scripts and block lists in this directory are from
[Life's Good Without Spying](https://github.com/lewisdoesstuff/lifesgoodwithoutspying)
by Lewis Wood, MIT, © 2026 Lewis Wood. The licence text is
`app/licenses/LifesGood-MIT.txt`.

Slopium keeps them here so one install can apply the same switches. The file
names use `slopium-privacy` instead of `lifesgoodwithoutspying`, so this copy
does not write that app's settings, hosts file, or log.

`privacy.sh apply` and `privacy.sh boot` do nothing while
`/var/lib/webosbrew/init.d/50-lifesgoodwithoutspying` is still installed.

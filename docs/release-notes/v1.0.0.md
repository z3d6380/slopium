# Slopium 1.0.0: a calm home screen with a setting for almost everything

**Slopium** replaces the busy LG home screen with a quiet one: a clock, a weather card, your apps and inputs in one row, a recent-apps panel with "Close all", and a wallpaper that is a picture, a slideshow or plain black. It is for people who like to tune every detail: there are **more than 60 settings**, and nearly every look, colour, size, position and timing can be changed.

> **Read this first.** Slopium is a personal, open-source hobby project provided **as is, with no warranty**. Most features need a **rooted TV** (Homebrew Channel) and run commands with **root privileges**, which can void your warranty or cause problems. ## Highlights

- **Clock.** 14 styles (Plain, Frosted card, Stacked, Digital LED, Dot matrix, Nixie tubes, Analogue dial, Flip clock, Calendar page, Sun arc, Day timeline, Words, Binary dots, Progress rings), 16 typefaces, 8 thickness steps from Thin to Black (it thickens the whole clock, not just the digits), size, colour, opacity, position, 12/24-hour, date and AM/PM switches.
- **Weather card.** Current conditions, hourly curve and 7-day forecast (8 card layouts) from Open-Meteo, with its own theme, accent, line and dot colours, size and position. No account needed.
- **Themes everywhere.** Pick a theme for the clock, the weather card, the icons and the settings screens: Match the wallpaper, Transparent, Sunset, Aurora, Midnight, Ocean, Forest, Candy, Violet, Paper, Mono, Neon, and more, each with its own accent colour. Optional **master sync** switches make the clock, weather card and icon boxes follow the wallpaper.
- **Apps and inputs.** One tidy row. Choose, re-order, hide, rename, change icons; clean monochrome "marks" or original icons; icon size, opacity, tile shape, rows, side and bottom margins, spacing, box and title colours.
- **Recent apps panel.** Press **Back** on the home screen to see the apps in memory; open one, hold OK to close it, or **Close all**. You choose its width and height. *(Rooted TV.)*
- **Wallpaper.** Black, one picture, or a slideshow of the built-in wallpapers or your own pictures from a USB drive. Opacity, a bottom fade you can shape (darkness, height, curve, colour), and a shuffle that remembers its order so every picture plays once before any repeats.
- **Quiet mode and burn-in care.** After a time you choose, the icon row hides and only the clock and weather remain. They move to a new spot on a fixed timetable, your choice of **fade out and reappear**, **glide**, **jump** or off; wallpaper changes are timed never to land on a move. Plus an optional OLED pixel shift. Any key brings everything back instantly.
- **Light on weak TV hardware.** Draws from saved data first, redraws the clock once a minute, and has no animation when you return from quiet mode.

## Install (recommended: Homebrew Channel, with automatic update notices)

1. Open the **Homebrew Channel** on your TV and go to **Settings**.
2. Choose **Add repository** and enter exactly:

   ```
   https://raw.githubusercontent.com/z3d6380/slopium/main/repo/apps.json
   ```
3. Go back to the app list, open **Slopium** and choose **Install**.

From then on the Homebrew Channel shows an **Update** button whenever a new version is published here. The exact menu wording can differ a little between Homebrew Channel versions.

**No on-screen keyboard fun:** from a computer on the same network you can add the repository over SSH instead:

```sh
ares-launch org.webosbrew.hbchannel -p '{"launchMode":"addRepository","url":"https://raw.githubusercontent.com/z3d6380/slopium/main/repo/apps.json"}'
```

### Or install the file yourself

Download `io.github.batmanrises.slopium_1.0.0_all.ipk` from the **Assets** below and install it with [webOS Dev Manager](https://github.com/webosbrew/dev-manager-desktop), or over SSH:

```sh
scp -O io.github.batmanrises.slopium_1.0.0_all.ipk root@TV_IP:/tmp/
ssh root@TV_IP
luna-send -i luna://com.webos.appInstallService/dev/install '{"id":"com.ares.defaultName","ipkUrl":"/tmp/io.github.batmanrises.slopium_1.0.0_all.ipk","subscribe":true}'
luna-send -n 1 luna://com.webos.applicationManager/launch '{"id":"io.github.batmanrises.slopium"}'
```

## Good to know

- **Needs:** an LG TV on webOS. For the full feature set (live app list with icons, the Recent apps panel, closing/uninstalling apps, USB wallpapers, TV input) the TV must be **rooted with the Homebrew Channel**. Without root Slopium is designed to fall back to its core features; that fallback is inherited from Hearth and has not been verified on a non-rooted TV by this project.
- **Installs next to Hearth.** Slopium has its own app ID (`io.github.batmanrises.slopium`), so it does not replace Hearth and uses its own settings and files. Both launchers can offer "replace LG Home", which patches a system file: turn that on in **only one** launcher at a time.
- **Fresh installs start with a ready-made look** (listed in the [README](https://github.com/z3d6380/slopium#settings-a-fresh-install-starts-with)); everything can be changed in Settings.
- **Tried on the maintainer's own TV.** Other models and firmware versions may differ. Please open an issue with what you find.
- **Weather** is sent only as latitude/longitude to Open-Meteo. There is no advertising, analytics or telemetry.

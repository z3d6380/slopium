# Slopium 1.0.12

Pressing Home no longer flashes. The watcher that kept pulling another copy of Slopium forward is gone.

Restart and Power off are small icons in the top-right corner, out of the HDMI chips. Press an icon once, then press it again. They use the TV's own power service.

The boot-time Wi-Fi recovery no longer switches the radio off while the network status is still unknown.

# Slopium 1.0.13

Restart uses the same reboot call as Homebrew Channel. Power off uses the TV’s power service. Both icons respond without changing another setting first.

Up from the top row still opens the weather card. Up again moves to the status row, the HDMI chips, and the power icons. Left and right move between them, and OK does what a click does. Down or Back returns to the apps. With the weather card off, the first Up goes straight to those widgets.

Wi-Fi recovery is a switch under Settings → Options. It stays on after a reinstall. If Wi-Fi is still down after the TV starts, it turns the radio off and on once. A connection that is already up is left alone.

The first Home press can still load the Home copy of this screen. Later presses on that copy stay put.

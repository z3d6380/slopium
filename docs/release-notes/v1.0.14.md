# Slopium 1.0.14

Wi-Fi recovery no longer turns the radio off and on. A radio that is already on is left alone. The script only turns it on when it is actually off, and it waits until Homebrew has finished starting.

Power-cycling the radio was followed by a reboot before Homebrew cleared its failsafe flag. The next boot then showed failsafe mode and skipped Wi-Fi recovery.

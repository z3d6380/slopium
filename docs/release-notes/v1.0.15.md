# Slopium 1.0.15

Rebooting once Slopium is on screen no longer leaves Homebrew in failsafe mode.

Homebrew sets a flag at the start of its startup script and removes it only when that script finishes. The picture is already up before then, so a reboot to check the set was counted as a crash. The next boot showed failsafe and skipped the root startup scripts.

The flag is removed as soon as this boot creates it. If a previous startup really did not finish, that flag is left in place for Homebrew's own check.

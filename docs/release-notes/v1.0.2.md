# Slopium 1.0.2

The Home button can open Slopium directly. On a webOS 11 TV, where LG Home is a Flutter app, turning on "Make this launcher the default instead of LG Home" mounts Slopium in that app's place. LG's files stay underneath, and turning the switch off puts them back. On a TV that cannot reread Home, the previous helper is still used.

Settings are kept in one shared file, so the Slopium tile and the Home button show the same layout. A failed read no longer replaces that layout with the built-in defaults.

`tools/wifi-recover.sh` is included for a set whose Wi-Fi does not connect until it is switched off and on. The app does not run it by itself.

# Slopium 1.0.3

The System tile opens picture, sound, network, and general settings in Slopium's own pages. Support still has a row that opens the TV's menu for channels, accounts, and the rest.

Settings → Status adds a quiet row on the home screen: the connection icon, Wi-Fi signal, processor, memory in use, and free app storage. Each reading can be turned off, and the row can be moved like the clock. It hides while the screen is resting.

Settings → Options → Privacy applies the Life's Good Without Spying switches (MIT, Lewis Wood). Apply says Applied and stays idle until a switch changes. Profiles are Max, Strong (recommended), Normal, Minimum, and Off. A boot script puts the same apply back after a restart. Turn Content Store off for the Apps store to open.

The Apps store is included in the app list. The LG Home tile can be hidden like any other app.

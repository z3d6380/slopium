# Slopium 1.0.4

Settings → Options → Memory chooses which apps may stay loaded when you have not opened them. Off, the usual choice, unloads an app the TV started on its own and leaves it unloaded until you open it. An app you opened and left by going Home stays either way.

Long menus glide to the next row. The highlight settles in one place and the rows slide past it.

Settings → Status → Keep while resting leaves the status row up with the clock and weather when the menu hides. It is off until you turn it on.

Pressing Home while Slopium is already showing stays on the same page. The older helper that opened the tile on top of Home stays off once Slopium is mounted in Home's place.

Privacy's ad and voice stand-ins stay up. If AmazOff is installed, Apply keeps Prime's artwork name in the hosts file.

# Slopium 1.0.6

A row of HDMI chips sits on the home screen. Each chip shows the name the TV has for that port. It says Off when nothing is connected, Plugged when a cable is in, and On when a picture is coming through. Point and click a chip to open that input.

Settings → Status can turn the row off, hide any port, show only plugged-in ports, move and resize the row, and keep it up with the clock and weather when the menu hides.

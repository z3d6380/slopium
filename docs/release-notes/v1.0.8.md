# Slopium 1.0.8

Turning on “replace LG Home” now installs the boot links for Home, memory, privacy, and HDMI ads, and adds an early hook to Homebrew’s startup script. After a restart, that hook mounts Slopium and, when update blocking is on, covers the update program before the rest of startup. It does not change LG’s signed developer-mode script.

If another app is in front when the Home button is pressed, Slopium closes that app and comes forward.
